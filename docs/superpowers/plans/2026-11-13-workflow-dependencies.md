# Внешние зависимости workflow

**Цель:** устанавливать Superpowers и Plannotator вместе с китом через официальные плагины и установщик CLI.

**Решение:** общий реестр плагинов и идемпотентный Bash-установщик для Claude Code. Настройки объединяются существующим `mods/merge-plugin-settings.js`; явное отключение сохраняется. Plannotator CLI устанавливается официальным установщиком в режиме `--minimal`, чтобы не менять интеграции других агентов. Codex подключается отдельно по официальным инструкциям.
