## Modern Web Guidance (Google Chrome)

- **Источник:** https://github.com/GoogleChrome/modern-web-guidance
- **Дата записи:** 2026-11-18
- **Статус:** идея, к реализации не приступали

### Что это

Скилл от Chrome, Edge, Firefox и MDN. Содержит около 260 коротких гайдов по современной веб-платформе: CSS, формы, a11y, производительность, popover и dialog, view transitions, built-in AI. Цель: не дать агенту писать устаревший код.

- Гайды лежат в `skills/modern-web-guidance/guides/`. Скилл получает их через `npx modern-web-guidance@latest search` и `retrieve`.
- Есть `legacy-scan <path> --json`, который ищет устаревшие паттерны в кодовой базе. Он покрывает около 20% гайдов.
- Скилл по умолчанию считает безопасными фичи уровня Baseline Widely available. Для остальных гайды требуют fallback.

### Зачем нам

`rules/angular/` покрывает только Angular-специфику: компоненты, формы, DI. Про CSS, a11y, диалоги и производительность там ничего нет. Скилл закрывает этот пробел, и дублировать гайды вручную не нужно.

### Как применить

1. **`setup.sh`, шаг 6.** Добавить установку скилла рядом с `angular-best-practices`, по признаку фронтенда (`@angular/core`, при желании любой `package.json` с html/css).
   - Вероятная команда: `npx skills add GoogleChrome/modern-web-guidance --skill modern-web-guidance -a claude-code --yes`. Не проверено, структура `skills/` стандартная.
2. **`rules/orchestrator.md`.** Добавить строку маршрутизации «HTML/CSS/a11y/клиентский JS → скилл `modern-web-guidance`». Задать приоритет: `rules/angular/*` главнее гайдов, а гайды дают платформенные детали. Их примеры на ванильном JS, в Angular их надо адаптировать.
3. **Политика поддержки браузеров.** Завести ключ `browserSupport` в `.claude/dev-conventions.json`, а `orchestrator.md` читает его в разделе «Project Config». Скилл сам предлагает такую политику (например, «Allow Newly Available features с лёгким fallback»).
4. **`legacy-scan` как необязательный шаг** в `skills/roadmap` или `skills/update-ai-dev-kit`: просканировать фронт на устаревшие паттерны.

### Риски и вопросы

- **Сеть и `npx` во время выполнения.** Каждый поиск ходит в npm. Нужны разрешения и allowlist `npx -y modern-web-guidance@latest *`. Скилл закрепляет версию через `--skill-version`, но сам пакет берётся с `@latest`.
- **Агрессивный `SKILL.md`.** Написано «MANDATORY, выполнять ПЕРВЫМ для любого HTML/CSS». Это противоречит нашей схеме с always-on только `core.md` и маршрутизацией по таблице. Возможно, придётся ограничить срабатывание нашей строкой в `orchestrator.md`.
- **Раздел `### Modern Web Guidance` в ответе.** Скилл требует добавлять его в конце ответа, на английском. Решить, оставляем ли это при нашем правиле «отвечать по-русски».
- **Чужой, часто обновляемый контент.** Править нельзя, только обновлять через `npx skills update`.
- **Адаптация под Angular.** Гайды на ванильном JS. Нужна проверка, как они ложатся на Angular (SSR-guard, типы атрибутов вроде `popover`, `commandfor`).
