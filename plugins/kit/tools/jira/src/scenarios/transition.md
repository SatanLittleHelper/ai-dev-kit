# Ручная проверка перехода в работу

Выполняйте из проекта с настроенным `jira.baseUrl`. Используйте тестовую задачу, у которой в текущем статусе доступен прямой переход в «В работе».

Целевой статус по умолчанию берётся из `JIRA_STATUS.IN_PROGRESS`. В меню Jira команда читает метку статуса назначения отдельно от названия действия. Для классического интерфейса без метки назначения можно задать точное имя действия.

1. Проверьте сессию командой `node <путь-к-jira>/cli/main.mts status`. При коде 2 выполните `login` и войдите в Jira в открытом окне.
2. Выполните `node <путь-к-jira>/cli/main.mts transition <ключ> --dry-run`. Проверьте карточку и меню в видимом Chrome, затем закройте окно. CLI возвращает `status: "dry-run"` и исходный статус. При наличии нескольких переходов в «В работе» настройте `jira.inProgressTransition` на точное имя нужного действия. Если целевой статус называется иначе, задайте `jira.inProgressStatus`.
3. Выполните `JIRA_HEADLESS=0 node <путь-к-jira>/cli/main.mts transition <ключ> --no-dry-run`. Проверьте, что CLI возвращает `status: "transitioned"`, URL тестовой задачи и фактический статус «В работе».
4. Повторите команду. Jira CLI возвращает `status: "already-in-progress"` с тем же ключом и оставляет карточку в том же статусе.
5. Для проверки `flow` запустите `flow start <ключ>`, затем `JIRA_HEADLESS=0 flow next --task <ключ> --no-dry-run`. После подтверждения Jira текущей становится стадия `spec`, в доказательстве стадии `in-progress` сохраняется URL карточки.
